# Go Go Hankuk — hosting files

Upload all files in this folder to your hosting web root (usually public_html), keeping index.html at the root. No build command is needed. For Netlify, drag this folder into Netlify Drop.

Includes the updated navigation, 33 university logos, admissions checklist, About Us additions, contact footer and October 2026 news story.

The Student Portal is currently a demo. Configure your own Firebase project using firebase-config.js and firestore.rules before collecting real applications.

The About Us video is a clearly labelled sample preview; connect your own YouTube video when available. Existing student stories are also labelled sample testimonials.

Edit content.js for programs, news and image URLs. Some original photos and Google Fonts require an internet connection. Language switching is included; newly added content falls back to English where a translation has not been supplied.
